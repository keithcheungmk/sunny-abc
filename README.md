# Sunny ABC

Cartoon phonics for kids under 6, tuned for iPad. Learn letter sounds A–Z, play **Listen & Tap**, and try **Picture Match**.

## Features

- **Learn Letters** — big letter, picture, and spoken phoneme
- **Listen & Tap** — hear a sound, tap the matching letter
- **Picture Match** — see a picture/word, pick the first letter
- Large touch targets, landscape-friendly layout, sunny cartoon look
- Speech uses the device voice (`speechSynthesis`) — no API key needed

## Play online

https://keithcheungmk.github.io/sunny-abc/

## Run locally

```bash
npm install
npm run dev -- -p 3847
```

Open [http://localhost:3847](http://localhost:3847).

## Notes

- Best with sound on (iPad / Safari may need one tap before voices play).
- English short-vowel / hard-consonant first sounds for ages ~3–6.
